# MLR_50_Startups_profit_prediction

# 🚀 50 Startups Profit Prediction using Multiple Linear Regression


# 📊 Project Overview

This project predicts the **profit of startup companies** using **Multiple Linear Regression**. The model analyzes startup expenditures and estimates the expected profit based on historical business data.

The prediction is performed using the following factors:

✅ Research & Development Spend  
✅ Administration Cost  
✅ Marketing Spend  
✅ State Location

The project also includes a **Flask Web Application** that allows users to enter startup details and instantly obtain profit predictions.

---

# 🎯 Project Objective

The primary objective of this project is to:

- Analyze startup expenditure data.
- Train a Multiple Linear Regression model.
- Predict future profit values.
- Provide an interactive web interface for users.
- Demonstrate machine learning model deployment using Flask.

---

# 📁 Dataset Information

The dataset contains information about 50 startup companies.
